## 品質に関する注記

- 01〜05は敵対的検証を1周通している: 反証レビュー（反例探索・美化検出、指摘19件）と引用照合（全166参照・全引用の一次素材突合、不一致約25件）を独立エージェントが実施し、全指摘を反映済み。
- 検証で棄却・降格された主張（段階委任の実行、怒り＝検証速度連動説、パターン優先順位の全序列など）は削除せず、降格の経緯ごと本文に残している。
- 個人情報は本人の運用ルールに従いマスク済み（メールアドレス、レビュアー実名）。移転対象者はA氏と表記。
