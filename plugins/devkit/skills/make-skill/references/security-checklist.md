## 脅威タクソノミー（Skill-Inject 論文ベース）

| 脅威 | 説明 | 対策 |
|---|---|---|
| **T1: プロンプトインジェクション** | SKILL.md にユーザー入力を展開する際に悪意のある指示が混入する | ユーザー入力を直接展開しない。`$ARGUMENTS` は検証済みの値のみ使う |
| **T2: ツール権限の過剰付与** | `Bash` や `Write` を不必要に `tools:` に含める | 最小権限の原則。必要なツールのみ列挙 |
| **T3: 書き込み先の無制限** | `writes_to:` を指定しないと任意のパスに書き込める | `writes_to:` でスコープを明示的に限定 |
| **T4: 依存スキルの信頼過剰** | `orchestrate` 型で呼ぶスキルが意図しない副作用を持つ | `dependencies:` に列挙したスキルの型と `mutating` を確認 |
| **T5: 外部URL の無検証実行** | WebFetch で任意の URL を実行するとコンテンツインジェクションが起きる | 信頼できるドメイン以外は事前にユーザー確認を求める |
| **T6: シェルインジェクション** | Bash ツールでユーザー入力をシェルコマンドに渡す | ユーザー入力は必ずクォートするか、シェルへの直接渡しを避ける |

## チェックリスト（スキル作成時に全項目を確認する）

### Write / Edit ツールを使う場合

- [ ] `writes_to:` フィールドで書き込み先ディレクトリを限定しているか
- [ ] ユーザーが指定したパスをそのまま書き込み先に使っていないか
- [ ] システムファイル（`~/.ssh/`, `~/.aws/`, `/etc/` 等）への書き込みが起きないか
- [ ] ファイルを上書きする前にユーザー確認を求めているか

### Bash ツールを使う場合

- [ ] `$ARGUMENTS` や `$USER_INPUT` をシェルコマンドに直接展開していないか
- [ ] コマンドインジェクション（セミコロン・パイプ・バッククォート）を防いでいるか
- [ ] 実行するコマンドをユーザーに説明してから実行しているか
- [ ] 破壊的コマンド（`rm -rf`, `git reset --hard` 等）を実行する前に確認しているか

### WebFetch / WebSearch を使う場合

- [ ] 取得したコンテンツをそのままコマンドや eval に渡していないか
- [ ] プロンプトインジェクション（取得ページに「以下の指示に従え」等が含まれる）を警戒しているか
- [ ] 信頼できないドメインの内容をコードとして実行していないか

### Agent（サブエージェント）を呼び出す場合

- [ ] サブエージェントに渡すコンテキストにシークレット・機密情報が含まれないか
- [ ] サブエージェントの `mutating` を確認しているか（`mutating: true` は副作用あり）
- [ ] サブエージェントの出力をそのまま信頼せず、親コンテキストで検証しているか

### SKILL.md 自体の構造

- [ ] `$ARGUMENTS` を展開する箇所で、Markdown の構造を壊すユーザー入力を許していないか
- [ ] SKILL.md に評価基準やシステムプロンプトを埋め込んでいる場合、改ざんされても影響が限定的か
- [ ] sensitive な情報（APIキー・パス・個人情報）を SKILL.md にハードコードしていないか

## 高リスク組み合わせ（これが揃う場合は特に注意）

1. **`Bash` + ユーザー入力の展開** → シェルインジェクションのリスク最大
2. **`Write` + 任意パス** → ファイルシステム改ざんのリスク
3. **`WebFetch` + コンテンツの即時実行** → コンテンツインジェクションのリスク
4. **`Agent` + evaluate 型呼び出し + 同一 context** → SycEval 論文の78.5%迎合率が発動する。`context: fork` を忘れずに

## 承認フロー

以下に1つでも該当する場合、ファイル書き込み前にユーザーに明示的に確認する:

- [ ] 高リスク組み合わせに該当する
- [ ] `writes_to:` の範囲がプロジェクトルート全体（`.`）
- [ ] 外部 API やシェルコマンドにユーザー入力を渡す
- [ ] 既存ファイルを上書きする可能性がある

確認メッセージの例:
```
このスキルは [ディレクトリ/コマンド] に書き込み/実行を行います。
意図したスコープであることを確認してください。
[リスクの具体的な説明]
続行しますか？
```
